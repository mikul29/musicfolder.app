This page lists what changed in each version of Music Folder, newest first. The guides always describe the current version. To see which version you have, check the App Store page for Music Folder or the app's Account page.

## Music Folder 4.3

Sharing folders and set lists was rebuilt. You can now share a folder or set list with other musicians, choose who can edit, and restore pieces that someone removed. Everyone you invite needs Music Folder 4.3 or later.

- **Shared folders and set lists.** Invite other musicians to work on the same folder or set list, and changes sync to everyone. See [Share a folder or set list](/guide/share-a-folder-or-set-list).
- **Updated sharing.** If you already share folders or set lists from an earlier version, you'll need to move them to the new sharing and invite your members again.
- **Recently Removed.** A piece removed from a shared folder can be restored. See [Work together in a shared folder or set list](/guide/work-together-in-a-shared-folder-or-set-list).
- **Previous Version.** View and restore an earlier version of a shared PDF or chord chart for up to 30 days.
- Music Folder 4.3 needs iOS 17 or iPadOS 17 or later.

## Music Folder 4.2 and 4.2.1

A visual refresh with new folder covers and a redesigned Home screen. Bookmarks became sections, which any piece of music can have, and each section can carry its own key, tempo and time signature (see [Add sections to a book](/guide/add-sections-to-a-book)). Set lists and importing were improved, and sharing a folder or set list became part of Premium for everyone taking part. 4.2.1 followed with fixes.

## Music Folder 4.1

A large release for performers: [Performance Mode](/guide/use-performance-mode), [Page Links](/guide/jump-to-repeats-with-page-links) for repeats, [Face Gestures](/guide/turn-pages-hands-free) for hands-free page turns, Half-Page Turns, a dark background for sheet music, music symbols for annotation, Organize Pages, page-turner setup, tempo and key changes for recordings, set-list timing and practice insights.

## Music Folder 4.0

[Chord charts](/guide/create-a-chord-chart) with transposition, converting chord-sheet PDFs into charts, Planning Center chord charts, [annotation layers](/guide/use-annotation-layers), Two-Page View on iPad and Mac, and [library backup and restore](/guide/back-up-and-restore-your-library).

## Music Folder 3.3 and 3.3.1

Recordings keep playing in the background with lock-screen controls. Updates to the iPad piano and faster Planning Center loading. 3.3.1 changed the set-list layout, added support for larger screens and resizable windows, keyboard shortcuts, and importing by drag and drop.

## Music Folder 3.2 and 3.2.1

[Notes](/guide/keep-notes-on-a-piece) for each piece, better behavior alongside other audio apps, and more reliable practice tools.

## Music Folder 3.1 and 3.1.1

Sheet music can be read in landscape. 3.1.1 brought bug fixes and stability improvements.

## Music Folder 3.0 and 3.0.1

A new design with four tabs, sharing for folders and set lists, Planning Center, practice goals and streaks, a new piano, tone generator and metronome, and browsing free sheet music. 3.0.1 fixed a crash when sharing on iPad during set lists and made sharing and bulk delete more reliable.

## Earlier versions

Version 2.6 added a guitar mode and alternate tunings to the tuner, and continuous vertical scrolling in the reader. Version 2.5 added audio recordings for play-along. Version 2.4 added free public-domain sheet music and searching the library by composer. Version 2.3 introduced the tuner, with adjustable concert pitch and a reference tone. Versions 2.1 and 2.2 brought text annotations, sharing PDFs with their annotations, an expanded metronome, music books with bookmarks, bulk import, sharing groups and set lists, and a redesigned interface.
